# 行列のできるカフェ 〜案内人編〜

お店が「○人くださ〜い」と言ったら、ゲートを開け閉めして**ぴったりの人数**を案内するブラウザゲームです。制限時間は60秒です。

## 遊び方

- 「開ける / 閉める」ボタン(PCではスペースキーでも可)でゲートを開け閉めします。
- ゲートを開けている間、送り出す速度は 2人/秒 から 10人/秒 まで加速します。閉めると元の速度に戻ります。
- 閉めた時点で集団の人数が確定し、店に着いたときに判定します。人数がぴったりなら成功、多くても少なくてもミスです。
- 得点は成功1回ごとに `(人数 × 10 + 100) × コンボ倍率` です。コンボ倍率は連続成功ごとに +0.2 され、最大 3.0 倍です。

## 構成

- `index.html`:画面構成
- `style.css`:レイアウトと配色(ポップで固定)
- `game.js`:ゲームロジックと Canvas 描画
- `ranking.js`:ランキング(サーバーがあればサーバーに、無ければこの端末に保存)
- `server.js`:自分のPCで動かすサーバー(ゲームの配信とランキングAPI)
- `start.bat`:サーバーをダブルクリックで起動する

## 遊び方の種類

| 開き方 | ランキング |
| --- | --- |
| `server.js` で起動して開く | みんなで共有(サーバーの `data/rankings.json` に保存) |
| `index.html` を直接開く / GitHub Pages | その端末だけ(ブラウザに保存) |

どちらになるかは自動で判定します。

## 自分のPCでサーバーを動かす

1. [Node.js](https://nodejs.org/ja) の LTS 版をインストールする(npm install は不要です)
2. `start.bat` をダブルクリック(またはこのフォルダで `node server.js`)
3. ブラウザで `http://localhost:3000` を開く

止めるときは、黒い画面で `Ctrl + C` を押すか、画面を閉じます。
ポートを変えたいときは `set PORT=8080` を実行してから `node server.js` で起動します。

### 同じWi-Fi・LANの人に遊んでもらう

起動したときに表示される `同じネットワークから: http://192.168.x.x:3000` のアドレスを伝えます。
初回に Windows のファイアウォールの確認が出たら「プライベートネットワーク」を許可してください。

### インターネットの外の人に遊んでもらう(Cloudflare Tunnel)

ルーターの設定をしなくても、一時的な公開URLを作れます。

1. cloudflared をインストールする(コマンドプロンプトで `winget install --id Cloudflare.cloudflared`)
2. サーバーを起動したまま、別のコマンドプロンプトで次を実行する

   ```
   cloudflared tunnel --url http://localhost:3000
   ```

3. 表示される `https://〜.trycloudflare.com` のURLを伝える

このURLは起動するたびに変わり、PCを閉じると遊べなくなります。ずっと同じURLにしたい場合は、Cloudflare のアカウントを作って名前付きのトンネルを設定します。
学校や会社のネットワークでは外部公開が禁止されていることがあるので、使う前に確認してください。

## ランキングの仕組みと注意

- 「難易度 × 時間」の組み合わせごとに別のランキングです。上位10件を表示し、サーバーには各1000件まで保存します。
- サーバー側で、名前(1〜12文字)と数値の範囲をチェックし、同じ人の連続登録(5秒以内・1時間に60回まで)を制限しています。
- ブラウザで動くゲームなので、スコアの改ざんを完全には防げません。おかしな記録は、サーバーを止めてから `data/rankings.json` を編集して消してください。
- `data/` フォルダは `.gitignore` に入れてあるので、ランキングのデータは GitHub に上がりません。
